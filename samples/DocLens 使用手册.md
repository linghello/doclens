# DocLens 使用手册

> 一个纯离线、不要任何权限的本地文档阅读器。所有文件都躺在 App 自己的沙盒里，**不上传、不联网、不读你的相册**。

## 导入文档

1. 点右上角的 **＋** 按钮；
2. 选「导入文件」，在系统选择器里挑 `.md` 或 `.txt`（可以一次选好几个）；
3. 也可以用别的 App 里的「分享 → DocLens」直接丢进来。

## 新建与编辑

点右上角 **＋** → **新建文档**，就能在 App 里直接写：

* **插入图片** —— 点工具条上的「插入图片」，选张照片就插进正文；
* **背景** —— 给这篇文档配一张**半透明背景图**，还有 10% / 22% / 35% / 55% 的不透明度可选；
* **预览** —— 存好直接跳到阅读界面看效果。

想改已经导入的文档：阅读时点顶栏的 **编**。

## 手绘批注（圈点）

阅读时点顶栏的 **笔**，就能用手指在正文上圈点勾画：

* 批注**自动保存**，下次打开还在；
* 批注锚定在正文上，**换字号、换屏宽都不会跑位**；
* 再点一次 **笔** 退出（批注模式下页面不跟着手指滚，方便下笔）；
* 擦掉：阅读菜单 **⋮** 里有「撤销一笔批注 / 清空全部批注」。

## 外观与设置

首页右上角有一个 **设置** 按钮，点开可以：

* **外观** —— 浅色 / 深色 / 跟随系统，随点随换；
* **阅读字号** —— 调整正文大小（阅读时也能点右侧小圆条上的 `＋` / `−` 临时调）；
* **全局背景** —— 给整个 App 换一张背景图，**不透明度可用滑杆无级调节**；顶栏、弹层、悬浮坞都是半透明的毛玻璃质感，背景会透上来；
* 底部会显示当前的文档数量与占用空间。

> 想只给某一篇文档单独配背景？阅读时点 **⋮ → 文档背景（半透明）**。

## 阅读时的操作

* 右边悬浮的小圆条：**＋ / −** 调字号，A 是当前大小；
* 顶栏 **★** 收藏，**⋮** 打开更多菜单；
* 阅读进度会自动记住，下次点开直接停在原地。

## 支持的 Markdown 语法

| 语法 | 效果 |
| --- | --- |
| `# 一级标题` | 大标题 + 装饰线 |
| `## 二级标题` | 加粗 + 短竖条 |
| `**粗体**` `*斜体*` | 行内样式 |
| `~~删除线~~` | 划线灰字 |
| `` `行内代码` `` | 粉色等宽字 |
| 列表 / 任务清单 | 圆点 / 数字 / 勾选框 |
| `> 引用` | 左侧竖条卡片 |

- [x] 中英混排断行
- [ ] 写一篇自己的笔记

## 关于中英混排

中文字符是等宽方块（占两个西文字符的宽度），而英文单词不能从中间断开。所以排版引擎必须区分「CJK 字符」和「西文单词」两种断行单元，否则就会出现中文行尾留一大片空白、或者英文单词被劈成两半的问题。

DocLens 内置了自己的断行算法：CJK **逐字**可断，西文**整词**不断，还顺手处理了避头尾（行首不放 `，。、；：` 这类标点）。

## 隐私说明

- 不申请任何 Android 权限，包括存储权限；
- 导入的文件是**复制**一份进来，原文件删掉也不影响；
- 卸载 App 时数据一并清理干净。
