# DocLens 使用手册

> 一个纯离线、不要任何权限的本地文档阅读器。所有文件都躺在 App 自己的沙盒里，**不上传、不联网、不读你的相册**。

## 导入文档

1. 点右上角的 **＋** 按钮；
2. 在弹出的系统文件选择器里挑 `.md` 或 `.txt` 文件（可以一次选好几个）；
3. 也可以用别的 App 里的「分享 → DocLens」直接丢进来。

## 外观与设置

首页右上角有一个 **设置** 按钮，点开可以：

* **外观** —— 浅色 / 深色 / 跟随系统，随点随换；
* **阅读字号** —— 调整正文大小（阅读时也能点右侧小圆条上的 `＋` / `−` 临时调）；
* 底部会显示当前的文档数量与占用空间。

## 阅读时的操作

* 右边悬浮的小圆条：**＋ / −** 调字号，A 是当前大小；
* 顶栏 **★** 收藏，**⋮** 打开更多菜单；
* 阅读进度会自动记住，下次点开直接停在原地。

## 支持的 Markdown 语法

| 语法 | 效果 |
| --- | --- |
| `# 一级标题` | 大标题 + 装饰线 |
| `## 二级标题` | 加粗 + 短竖条 |
| `**粗体**` `*斜体*` | 行内样式 |
| `~~删除线~~` | 划线灰字 |
| `` `行内代码` `` | 粉色等宽字 |
| 列表 / 任务清单 | 圆点 / 数字 / 勾选框 |
| `> 引用` | 左侧竖条卡片 |

### 任务清单

- [x] 导入文档
- [x] 中英混排断行
- [ ] 写一篇自己的笔记

## 关于中英混排

中文字符是等宽方块（占两个西文字符的宽度），而英文单词不能从中间断开。所以排版引擎必须区分「CJK 字符」和「西文单词」两种断行单元，否则就会出现中文行尾留一大片空白、或者英文单词被劈成两半的问题。

DocLens 内置了自己的断行算法：CJK **逐字**可断，西文**整词**不断，还顺手处理了避头尾（行首不放 `，。、；：` 这类标点）。

## 隐私说明

- 不申请任何 Android 权限，包括存储权限；
- 导入的文件是**复制**一份进来，原文件删掉也不影响；
- 卸载 App 时数据一并清理干净。
